The formula

The 40-second fix video

Short-form (Shorts / Reels / TikTok) is the volume play — vertical, 30–50s, one problem each. Long-form "complete guides" come later for evergreen SEO.

0–5s · HOOK

Name the pain

State the exact problem + promise the fix. No intro, no logo. "Mac FaceTime too quiet even at max? 10-second fix."

5–15s · AGITATE

Show the dead end

Flash the settings people try (System Settings → Sound). "Doesn't fix it — macOS has no per-app volume."

15–38s · FIX

Demo SoundDial

Screen-record: open the mixer, drag that app up, done. Show the result. This is the payoff.

38–45s · CTA

Download

"Link's in the description." On-screen button + pinned comment. Optional: "save this profile" bonus tip = open loop.

  • Hook ≤ 5s. Biggest drop-off is 0–15s; below 50% retention there = hook failed.
  • No "what's up guys" / logo intro — costs 8–15% instantly.
  • Answer-first (inverted pyramid) — same reason it wins featured snippets.
  • One problem per video — matches how people search.
  • Show the result — the volume slider moving is the proof.
  • 3 CTA surfaces: on-screen, description link, pinned comment.
